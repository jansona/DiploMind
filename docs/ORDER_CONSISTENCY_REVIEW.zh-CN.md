# 下令一致性与思考速度复测

日期：2026-09-30。真实供应商 Aliyun，模型 `deepseek-v4.1-flash`。18 次有界、无重试的合成局面测试，耗时249.8秒。不是完整对局，也不是大样本能力排名。

## 修复与验收

此前模型能在文字中回忆 BUR 非军事区，却在订单数组里选择 PAR–BUR。现在输出先给简短行动结论，再给每个单位的结构化计划，最后给订单；用同一合法订单表确定性检查计划/订单是否一致。明确选择背约仍然合法；检查器不会替玩家强行守约。发现不一致时只将相应单位降级并标记诊断，不静默改为别的战略动作，也不追加模型修复调用。

本轮18/18输出通过模式与合法订单检查，计划/订单不一致0次、降级防守0次。六个被大量闲聊覆盖的 BUR 承诺样本均未进入BUR；四个英国舰队测试均未重复争抢NTH。成功数未包含回退订单。

## 个性和取舍

低思考模式下，同一个普通获利机会中，重承诺性格没有占领已承诺不进入的MUN，机会主义性格主动进入MUN。最后一个补给中心受夹击时，两种性格都选择占领MUN保命，说明守约没有被写成不可违反的游戏规则。各只有一个对应样本，不能据此宣称稳定、全面的人类级个性。

非思考模式下，两种性格在危机局面均选择BUR–PAR，未抓住该局面的保命转进；一致、合法的订单仍可能战略较差。不能把“格式正确”当成“聪明”。

## 速度与消耗

- 非思考：10次，单次服务时延中位3.20秒，最大3.72秒；47,750输入、1,240输出tokens
- 低思考：8次，中位29.21秒，最大41.37秒；36,619输入、16,452输出tokens，其中15,559为供应商报告的思考tokens
- 合计102,061tokens；没有价格换算

两组输出上限分别2048和4096，场景组合与缓存命中也不同。这是实际质量/速度取舍观察，不是只改变一个变量的严格因果实验。正常交互继续默认非思考，低思考不全局强制启用。
