# 技术架构 — 模块职责与接口

> 八个模块，各自独立开发与测试。Python 后端 + web 前端；全项目开源（接受 diplomacy 引擎 AGPLv3）。
> 谈判=轮次同步，非实时；难度=纯模型档位；AI 始终为自己赢，不放水。

## 通信模型（贯穿全局）
- 谈判每回合固定 5 轮（上限）；一轮内人+AI 同时写，轮末统一投递。
- 某 AI 收到的多方消息打包成一次上下文，**每条标来源**：「德国·群聊@你」「德国·群发」「德国·私聊」。AI 一次读完、分别回。
- @可点多国；私聊允许小群（几国私局）。
- 七国并发，延迟取最慢者，非七倍。预告共 5 轮，AI 不会误判被掐断。
- 提前结束：某一轮全员无消息 → 跳过剩余轮，直接下命令。无 done/准备按钮。
- 静默可恢复：玩家某轮不发只是这轮静默；若该轮收到消息，下一轮仍可继续发，直到全员一轮静默或到 5 轮上限。
- 防死循环：AI 谈完（如达成一致）就停发，不反复彼此确认；自然走向全员静默而终止。
- 每轮可选计时，主限人类玩家。

## 参考：AI_Diplomacy 可借鉴机制（仅借结构，勿拷代码，许可证非商用）
- 并发：每轮七国 `asyncio.gather` 并发生成，各国基于上一轮快照、同轮互不可见 → 与"轮末统一投递"一致。
- 消息打包：全局/私聊分块，私聊按对象分组，并抽近3条"待你回复"置顶 → 套用我们的来源标签。
- 私聊vs群发：LLM 吐 JSON，每条带 message_type+recipient，非法收件人降级全局；@多国/小群=recipient 扩列表。
- 衔接：谈判→可选planning→写diary→并发下令；谈判产物仅作下令提示、不强制 → 支持言行背离=背刺。
- 我方增量：全员一轮静默提前结束；隐藏意图层；态度模型评。

## 1. 操作引擎 OperationEngine
- 职责：复用 diplomacy，地图/合法走子/裁决/撤退造兵/存档。纯规则，不碰 LLM。
- 接口：`legal_orders(power)`→列表；`submit(power, orders)`→校验；`process()`→结算下一相；`save()/load()`→JSON 存档。
- 非法/格式坏：正常不该出现（LLM 只从合法列表选）。一旦发生=bug，记 error 日志 + 该国 hold，事后修，不用随机走子掩盖。

## 2. 编排器 Orchestrator
- 职责：年循环——春外交(≤5轮)→命令→结算→撤退→秋外交(≤5轮)→命令→结算→撤退→冬造兵→判胜负→存档。纯调度，不含规则/决策。
- 春秋谈判机制相同(同5轮)；区别仅在秋季结算后数中心、定造兵/淘汰，筹码更重。冬季造兵=微决策无谈判：AI 生成造/撤命令，人类点 web 地图；引擎仅校验数量(造兵=新增中心数)。
- 单轮判结束：收集窗，窗内每方一次机会，全收齐(人类发送/计时到，AI 各产一条或不发)即本轮止；整轮零消息→提前终止谈判，否则满5轮。
- 接口：`run_year()`、`negotiation_round(r)`、`collect_orders()`、`process_phase()`、`check_end()`(18中心/最大回合/平局)、`save()`。

## 3. 消息总线 MessageBus
- 职责：三态通道(大群广播/@点名/点对点私聊)，轮次同步投递；记录"谁跟谁聊"状态(玩家可见，私聊内容不可见)；每条带来源标签。
- 接口：`send(from,to,scope,text)`；`fanout(round)`→给每方打包带来源的收件；`status()`→关系连线。

## 4. AI 玩家 Agent（体验核心）
五步，独立调用、可单测：
1. **感知 perceive**（不调模型）：拼棋局状态+本轮带源收件+记忆摘要(关系/承诺/近3回合)+性格→prompt。
2. **更新记忆 update**：事实代码压（背叛入账本）；态度调模型（信任分±）。独立调用，写回记忆库。
3. **定隐藏意图 intent**（调模型）：私有短文=真目标/拉谁/坑谁/第几回合动手；默认延续微调；只喂自己，永不外发。
4. **谈判 negotiate**（每轮调模型）：基于意图+收件产出消息(可真可假，大群/@多国/小群)；谈完停发触发静默。
5. **下令 decide_orders**（回合末调模型）：从合法列表选，吐结构化命令；可背离承诺=背刺；非法即hold记日志。
- 意图/谈判/态度三者各自独立调用，不合并。每国每回合≈8次调用(态度1+意图1+谈判≤5+下令1)，七国并发→延迟头号变量，demo 实测。
- 性格：system prompt 注入5参数(侵略性/守信度/瞒骗区间/结盟倾向/目标盟友)，约束意图与谈判。

## 5. 记忆库 Memory（每国一份）
- 关系表 `{国: 态度分, 信任度, 敌友}` — **态度模型压**：信任/态度是主观判断，由 LLM 读事件后评分，非代码加减。
- 承诺账本 `{对象, 内容, 回合, 是否兑现, 剩余}` — 代码记。剩余=承诺倒计时(如"三回合不打你"=3，每回合减1，到0失效)；无时限标"永久"。
- 行动记录 `{回合, 行动方, 动作, 背叛?}` — 代码记。
- diary：每回合自述盘算；滚动摘要：旧回合压短，留近3回合细节。
- 接口：`record(event)`、`summarize()`、`relation(power)`、`commitments()`。事实代码压，态度模型评。

## 6. LLM 网关 Gateway
- 职责：OpenAI 兼容，统一接 ollama/GLM；按国分配异质模型(难度=档位)；结构化输出校验+重试；超限 hold 记日志；七国并发；可关 thinking 省延迟。
- 接口：`chat(model,messages,schema)`、`assign(power)→model`、`retry(n)`。每国可配模型/温度/上限。

## 7. Web 前端
- 视图：地图(单位/中心/移动)、三态聊天(大群/@/小群私聊，玩家私聊仅自己可见+"谁在聊"连线)、下令面板(点地图选命令)、编年史 tab(可展开非常驻)。
- 观战上帝视角(看全部对话+指令)仅观战模式可用。实时跟回合；断线读存档续。本地起，未来服务化。

## 8. 编年史 Chronicle
- 纯文本，可展开 tab。按年简述春/秋/冬发生了什么 + 公开发言。仅收公开信息(公开发言+落子结果)，私聊不进，不剧透暗盘。
- 接口：`generate(history)`→文本，分段防超上下文。

## 9. 可观测性 / Debug
- 统一结构化日志 + debug 面板，各模块开放只读 `snapshot()`，按回合/国家/通道筛，合成一条时间线。
- 透视范围：AI 隐藏意图、记忆全表(关系/承诺/行动/diary/摘要)、性格参数；所有对话原文(含玩家不可见暗盘)；每次 LLM 调用(prompt+响应+模型+耗时+token+重试+格式失败，可回放)；引擎(命令/校验/裁决/hold/error)；应用(时序/并发/存档/异常)。
- 区别：观战=看戏(对话+指令+地图)；debug=看内脏(意图+记忆+每次调用)。直接喂延迟/格式失败率实测。
