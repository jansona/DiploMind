# 最小 DEMO 验证清单

> 目标：验证头号风险——延迟与格式失败率，非完整游戏。3 国小局、跑通一回合。
> 本地已部署 ollama；主力模型 qwen3.5:9b。

## 任务
1. 接引擎：`pip install diplomacy`，3 国小局，跑通 legal_orders→submit→process。
2. 接网关：OpenAI 兼容连本地 qwen3.5:9b，结构化输出+重试，跑通一次 chat。
3. AI 下令：1 国五步精简版（感知→意图→下令），从合法列表出命令，实测格式失败率。
4. AI 谈判：2-3 国一轮并发发言，轮末投递带来源标签，测每国≈8次调用并发延迟。
5. 一回合闭环：谈判5轮(全员静默提前止)→下令→结算，记总耗时/token/失败。
6. Debug 日志：每次 prompt+响应+耗时落盘，可回放。
